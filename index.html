Privacy & data

Understand where your information goes.

  • Personality preferences and your API key are stored in browser local storage.
  • Chat history is kept in memory for the current page session and is not saved to a Persona account.
  • In local mode, prompts are processed on this device. In OpenAI mode, prompts and recent context go directly from your browser to the configured provider.
  • Persona does not operate an application server or collect analytics in this version.
  • Provider terms, data retention, and charges are controlled by your AI provider.

Do not enter a shared, employer-owned, or high-privilege API key in a public/shared device. Browser storage is not a secure vault.

About Persona

A personality layer for AI conversations. Persona is an independent project and is not affiliated with Apple or OpenAI.

The web app works alongside Siri; websites cannot replace Siri or change Apple's built-in assistant personality.
